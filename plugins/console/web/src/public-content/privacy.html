本政策适用于当前域名提供的 YesImBot 实例，由本实例管理员负责运营。隐私咨询、访问或删除请求请联系 。其他独立部署的 YesImBot 实例不属于本政策的运营范围。

我们处理哪些信息

  • 账号与使用信息：实例账号、登录会话、已接入平台的必要身份信息、你发送的消息和附件、助手回复、工具调用结果，以及维持服务所需的运行与安全记录。
  • Google 连接信息：授权后的账号标识、邮箱、名称、权限范围，以及用于维持连接的访问令牌和刷新令牌。我们不接收你的 Google 密码。
  • Google 服务内容：仅在已授权的功能和任务需要时访问 Gmail 邮件及其元数据、标签与草稿，Calendar 日历与日程，以及 Drive 文件的元数据与内容。你授权的实际范围以 Google 同意页为准。

这些信息如何使用

信息用于验证账号、维持服务连接、理解你的要求、执行工具操作、返回结果、保留任务上下文，以及排查故障和防止滥用。例如，处理「找出明天的会议」需要查询日历；处理邮件或文件任务可能需要读取相关正文。

本实例不出售 Google 用户数据，不将其用于广告、用户画像、信用评估，也不将 Google 用户数据用于训练或改进通用 AI 或机器学习模型。

AI 处理、共享与披露

为完成你发起的任务，相关消息、Google 工具返回的邮件、日历或文件内容，可能作为任务上下文发送给本实例所配置的 AI 模型服务。本实例不使用固定且适用于所有部署的模型供应商名单；连接前，你可以向管理员了解当前供应商、处理地区及其数据政策。管理员应仅选用满足本政策及 Google Limited Use 要求的处理服务。

数据仅在提供你可见的功能所必需时交给相应模型、托管或技术服务提供方处理，或按你明确指定的目的地发送。例如，你要求发送邮件时，邮件内容会交给 Google 并发送给指定收件人。敏感工具只有管理员能让机器人调用；在群聊中，机器人的回复以及它据工具结果（包括管理员要求使用的敏感工具）给出的内容，会对该群成员可见。

除获得你的同意、为安全排障所必需，或履行适用法律义务外，不允许人工查看 Google 用户数据。服务管理员在这些情况下可能获得必要访问权限。我们不会为与上述功能无关的目的披露数据。

存储、安全与保留

Google 授权令牌按实例隔离，并加密存放于服务器；加密密钥保存在受文件权限保护的独立文件中。这不等于所有聊天记录与工具结果都已加密。执行任务取得的内容可能保留在该账号的对话历史和任务上下文中，供后续对话使用。

连接信息在维持授权期间保留；断开连接会删除该连接在本实例保存的账号授权记录，并尝试向 Google 撤销令牌。对话历史、此前的工具结果和运行记录不会因断开 Google 自动删除，它们在提供历史功能、故障排查或依法保留所需期间保存。请通过下述方式申请删除不再需要的数据。

撤销授权与删除数据

  • 在 YesImBot「设置 → 能力 → Google 邮箱和日历」中选择账号并点击「断开」，停止该连接后续的 Google 访问。
  • 也可在 Google 账号的第三方连接中撤销 YesImBot 的访问权限。
  • 如需访问、更正或删除实例中的连接信息、对话记录、工具结果或账号数据，请联系 ，说明所涉实例账号和请求范围。管理员会核实身份，并在适用法律要求的期限内处理；依法必须保留的数据会说明原因。

删除 YesImBot 中的记录，不会撤回已经发给收件人或群成员的内容，也不会自动删除 Google 账号里的原始邮件、日程或文件。

Google API 数据使用承诺

YesImBot 对从 Google API 收到的信息的使用及向其他应用的转移，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

YesImBot's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

政策变更

政策变更会发布在本页并更新生效日期。涉及 Google 数据用途或共享范围的实质变化时，将在实施前告知用户，并按要求重新取得同意。
